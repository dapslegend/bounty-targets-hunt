# AUTHORIZATION

This campaign hunts **public bug-bounty programs** listed in the hourly dump
https://github.com/arkadiyt/bounty-targets-data (Hackerone, Bugcrowd, Intigriti,
YesWeHack, Federacy).

Rules:
- Only assets marked in-scope **and** eligible for submission on the assigned program.
- Read the live program policy URL before testing. Policy wins over the dump.
- Safe-harbor / disclosure terms of that program apply.
- No testing of out-of-scope, no DoS, no real-customer credential stuffing.
- Proof stays in `/work/bounty/shared/findings`. Do not exfiltrate PII.
